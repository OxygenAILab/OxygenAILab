# Oxygen AI Lab

> Breath for Agents.

Oxygen AI Lab 官网。专注 AI Agent 增强与生产力加速的研究型实验室门户，展示 10 个开源项目矩阵，覆盖核心运行时、认知引擎、记忆管理、I/O 性能、自主进化、代码工程、任务编排与 MoE 前沿研究。

## 技术栈

- **前端**：React 18 + TypeScript + Vite
- **WebGL**：Three.js + @react-three/fiber + @react-three/drei + @react-three/postprocessing
- **样式**：Tailwind CSS 3
- **状态**：Zustand
- **动效**：Framer Motion
- **路由**：React Router (HashRouter)

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
